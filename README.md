# 🛒 Carrinho de Compras

## Descrição
O **Carrinho de Compras** é um projeto desenvolvido com **Next.js** e **React** para explorar a funcionalidade de **React Context** em um simulador de carrinho de compras. Criado inicialmente para estudos pessoais, também foi utilizado para capacitar membros da **Code Empresa Júnior de Computação**, ensinando conceitos de gerenciamento de estado e desenvolvimento web.

## Funcionalidades
- **Simulação de Carrinho**: Adição, remoção e atualização de itens no carrinho.
- **Gerenciamento de Estado**: Uso de React Context para compartilhar dados do carrinho entre componentes.
- **Interface Simples**: Design intuitivo para exibir produtos e gerenciar compras.
- **Capacitação**: Material prático para treinamento de novos desenvolvedores.

## Tecnologias
- Next.js
- React
- TypeScript
- CSS (ou TailwindCSS, se aplicável)

## Instalação
1. Clone o repositório:
   ```bash
   git clone https://github.com/Santannafe12/shopping-cart
   cd shopping-cart
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Execute o projeto:
   ```bash
   npm run dev
   ```
   - Acesse em `http://localhost:3000`.

## Como Usar
- **Adicionar Itens**: Clique em produtos para adicioná-los ao carrinho.
- **Gerenciar Carrinho**: Atualize quantidades ou remova itens via interface.
- **Explorar Contexto**: Estude o código em `context/CartContext.tsx` para entender o gerenciamento de estado.

## Observações
- Projeto voltado para aprendizado e capacitação pròpia.
- Ideal para iniciantes em React e gerenciamento de estado com Context.
